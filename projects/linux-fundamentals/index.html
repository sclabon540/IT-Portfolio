Linux Fundamentals Lab

Project Overview

This hands-on project documents my Linux fundamentals practice using Ubuntu on Windows Subsystem for Linux (WSL). I practiced commands useful for entry-level IT support and cybersecurity.

Skills Practiced

  • Navigating directories with pwd, ls, and cd
  • Creating and managing files and folders
  • Reading, copying, renaming, and deleting files
  • Viewing and changing file permissions with chmod
  • Checking system information and disk space

Commands Used

pwd, ls, cd, mkdir, touch, cat, cp, mv, rm, chmod, uname -a, and df -h.

Lessons Learned

I learned how to navigate the Linux filesystem, manage files, inspect and adjust permissions, and check basic system information. I also practiced verifying commands and their results.
