# Windows User Account & Permissions Lab

## Project Overview
This beginner-level IT support lab demonstrates how to inspect Windows 11 folder permissions and review effective access for a user account.

## Objective
Learn how Windows permissions control access to files and folders and how to use Effective Access to investigate a user's permissions.

## Tools Used
- Windows 11
- File Explorer
- Folder Properties
- Advanced Security Settings
- Effective Access

## Steps Performed
1. Created a test folder on the Desktop.
2. Opened the folder's Security settings.
3. Inspected the folder's permissions.
4. Used Effective Access to review my Windows account.
5. Captured a screenshot of the results.

## Findings
- Effective access was granted for 12 listed permissions.
- Two permissions were not granted:
  - Full control
  - Delete subfolders and files

These results were documented for learning purposes. A denied permission does not automatically indicate a problem.
